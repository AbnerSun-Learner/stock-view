## 项目简介

> 当前版本：**v0.4.x**（基于 Next.js App Router）

本项目是一个基于 **Next.js + TypeScript + Tailwind CSS** 的网格交易策略计算工具。

### 核心功能

- **网格交易策略计算器**：
  - 支持自定义网格参数（基准价、网格步长、资金配置等）；
  - 自动计算网格档位、买入卖出价格、预期收益；
  - 压力测试与策略对比图表；
  - 支持动态网格步长配置。

---

## 环境要求

- 推荐 Node.js：**>= 20.9.0**

  - 如果你本地安装了 `nvm`，可在项目根目录执行：

  ```bash
  nvm use 20
  ```

- npm：建议使用随 Node 20 一起安装的版本。

---

## 本地运行

1. **安装依赖**

   ```bash
   npm install
   ```

2. **启动开发服务**

   ```bash
   npm run dev
   ```

3. 在浏览器打开 `http://localhost:3000` 即可访问。

> 提示：
>
> - 访问 `/grid` 页面使用网格交易策略计算器。

---

## 功能说明

### 网格交易策略计算器（/grid）

- **参数配置**

  - 基本信息：最小交易单位、价格单位、基准价、最低价
  - 资金系数：每网格金额、金额倍数、利润预留倍数
  - 网格步长：小网、中网、大网步长配置
  - 动态网格：支持启用/禁用，可选择稳定或激进模式

- **策略生成**

  - 根据配置参数自动计算所有网格档位
  - 生成买入/卖出触发价、数量、金额等详细信息
  - 提供压力测试结果（最大回撤、预期收益等）

- **结果展示**
  - 策略对比折线图：展示网格策略与一次性买入的收益对比
  - 详细数据表格：展示每个网格档位的完整信息
  - 统计数据卡片：汇总关键指标

## 部署到 Vercel

### 快速开始

1. **推送代码到 GitHub**：

   ```bash
   git add .
   git commit -m "准备部署"
   git push origin main
   ```

2. **在 Vercel 中部署**：
   - 访问 [vercel.com](https://vercel.com) 并使用 GitHub 账号登录
   - 点击 **"Add New..."** → **"Project"**
   - 导入 `stock-view` 仓库
   - 部署完成

> 注意：本项目为纯前端应用，无需配置数据库或外部服务。

---

## 注意事项与扩展方向

- 网格交易策略计算器为本地计算工具，所有数据仅在前端处理，不会保存到服务器。
- 所有计算基于用户输入的参数，不依赖外部数据源。
