## 项目简介

> 当前版本：**v0.4.x**（基于 Next.js App Router）

本项目是一个基于 **Next.js + TypeScript + Tailwind CSS** 的网格交易策略计算工具。

### 核心功能

- **网格交易策略计算器**（`/grid`）：
  - 支持自定义网格参数（基准价、网格步长、资金配置等）；
  - 自动计算网格档位、买入卖出价格、预期收益；
  - 压力测试与策略对比图表；
  - 支持动态网格步长配置。

- **指数估值分位**（`/valuation`）：
  - 覆盖 20+ 宽基与行业指数；
  - PE / PB 双维度十年历史百分位；
  - 数据来源于 AKShare 乐咕乐股接口。

- **ETF 相关性**（`/correlation`）：
  - 输入持仓 ETF，给出两两走势相关与成分重叠的综合评分；
  - A 走势相关基于近 1 年 / 近 3 年 Pearson 相关系数；
  - B 成分重叠基于披露的最新季度前十大持仓权重；
  - 综合分按 A、B 等权加权，给出 4 档持仓建议；
  - 黄金、商品等非股票成分 ETF 自动降级为仅展示 A 分数。

## 环境要求

- 推荐 Node.js：**>= 20.9.0**

  - 如果你本地安装了 `nvm`，可在项目根目录执行：

  ```bash
  nvm use 20
  ```

- pnpm：项目通过 `packageManager` 固定为 `pnpm@10.23.0`，建议使用 Corepack 启用。

- Python（可选，仅在使用 `/valuation` 与 `/correlation` 时需要）：

  - 推荐 Python 3.10+；
  - 安装 AKShare：

  ```bash
  pip install akshare pandas
  ```

  - 如需指定 Python 解释器，可设置环境变量 `PYTHON_BIN`（默认 `python3`）。

## 本地运行

1. **安装依赖**

   ```bash
   corepack enable
   pnpm install
   ```

2. **启动开发服务**

   ```bash
   pnpm run dev
   ```

3. 在浏览器打开 `http://localhost:3000` 即可访问。

> 提示：
>
> - 访问 `/grid` 页面使用网格交易策略计算器；
> - 访问 `/valuation` 页面查看指数估值分位；
> - 访问 `/correlation` 页面分析 ETF 持仓的两两相关性。

## 功能说明

### 网格交易策略计算器（/grid）

- **参数配置**

  - 基本信息：最小交易单位、价格单位、基准价、最低价
  - 资金系数：每网格金额、金额倍数、利润预留倍数
  - 网格步长：小网、中网、大网步长配置
  - 动态网格：支持启用/禁用，可选择稳定或激进模式

- **策略生成**

  - 根据配置参数自动计算所有网格档位
  - 生成买入/卖出触发价、数量、金额等详细信息
  - 提供压力测试结果（最大回撤、预期收益等）

- **结果展示**
  - 策略对比折线图：展示网格策略与一次性买入的收益对比
  - 详细数据表格：展示每个网格档位的完整信息
  - 统计数据卡片：汇总关键指标

### ETF 相关性（/correlation）

- **输入**：6 位国内 ETF 代码，逗号 / 空格 / 换行分隔，至少 2 只、最多 10 只；可选择"近 1 年"或"近 3 年"时间窗口。
- **A 走势相关**：基于前复权日收益率的 Pearson 相关系数，负相关一律截断为 0。
- **B 成分重叠**：取最新季度披露的前十大持仓，按权重降序计算 `sum(min(wA, wB))`，权重不主动重新归一化。
- **综合分**：A、B 等权（各 0.5）加权，落入 4 档建议区间——`[0, 0.3)` 分散较好 / `[0.3, 0.6)` 存在一定重叠 / `[0.6, 0.8)` 相关性偏高 / `[0.8, 1]` 高度重复。
- **降级路径**：行情或成分缺失时返回部分评分，仅 A 或仅 B 不进入完整建议区间，并显式标注原因。
- **依赖**：本地需要可用的 `python3` 与 AKShare（参见下方"环境要求"）。

## 注意事项与扩展方向

- 网格交易策略计算器为本地计算工具，所有数据仅在前端处理，不会保存到服务器。
- 网格策略的所有计算基于用户输入的参数，不依赖外部数据源。
- 指数估值与 ETF 相关性页面会通过 Python 子进程调用 AKShare 拉取行情和成分数据；首次访问可能较慢，后续走内存缓存。
- ETF 相关性的 B 分数基于披露的前十大持仓估算：宽基 ETF（如沪深 300、中证 500）的 top10 权重总和较低，B 分数会被天然压制，请结合 A 走势分数综合判断。
