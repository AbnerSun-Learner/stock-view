<a id="背景与成功标准"></a>

## 背景与成功标准

**为什么要现在做**：用户需在统一心智下完成「列表扫描估值极端信号 → 详情看多周期价格与估值上下文 → 行业权重理解」。缺少 PB 列、单一筛选入口与详情侧估值/行业可视化时，链路易中断到站外工具。

**成功判据（可验收）**：

- 列表在窄屏可通过横向滚动保持表头不换行，列宽合理；搜索框唯一且位置固定于表格右上。
- 详情用户在少量交互内切换任意预设区间，并能从图上读出 70%/80% 回撤参照线含义（tooltip 辅助）。
- 仪表盘与水位图在不依赖指针交互时仍可读出 0–100 分位语义（配合文案/标签）；行业层级切换后图表与 **表头文案同步**。

<a id="sec-list"></a>

## 列表页 `/indices`

### 用户故事

- **L-R1**：列宽贴近表头与单元格真实字数，避免整块留白或过窄挤压。
- **L-R2**：同时扫描 PE 与 PB 的当前值与中长窗口分位（类别列不再展示）。
- **L-R3**：仅用 **一个搜索框** 缩小候选集，控件在 **表格卡片右上方**。
- **L-R4**：当「当前分位」同时低于近 5 年与近 10 年分位（三者均有有效数值）时，获得 **非单凭颜色即可理解** 的标注（浅色底 / 细轮廓 + `title` 或等价无障碍说明）。

### 功能规格与验收

| #      | 需求                                                            | 验收要点（Given / Then）                                                                                                                                                                                                                                                      |
| ------ | --------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **L1** | 列宽 **自适应内容**                                             | `table-layout: auto`（或等价）；表头与单元格参与最小宽度计算；桌面端无不合理空白列                                                                                                                                                                                            |
| **L2** | 表头 **不换行**                                                 | `white-space: nowrap`；窄屏 **表格外层横向滚动**，不压缩折行                                                                                                                                                                                                                  |
| **L3** | 移除 **类别**                                                   | 列表不渲染类别列；数据层可保留字段供 MOCK                                                                                                                                                                                                                                     |
| **L4** | 增加 **当前 PB**、**近 5 年分位（PB）**、**近 10 年分位（PB）** | 与 PE 侧并列可读；缺失显示「—」。为实现 §列表-5 的 **PB 百分位比较**，须具备 **当前 PB 分位** 字段（可与「当前 PB」分列）；缺失则 PB 侧标注规则不触发                                                                                                                         |
| **L5** | **单一搜索**                                                    | 关键词搜索代码或名称；置于 **表格卡片内右上**；`aria-label` 清晰；触摸目标高度 ≥ 44px                                                                                                                                                                                         |
| **L6** | 分位极端 **样式标注**                                           | **PE**：当前 PE 分位相对近 5 年、近 10 年 PE 分位，`当前 !== null` 且 `当前 < min(近5年, 近10年)`（严格小于）则标注。**PB**：对 **当前 PB 分位** 与同口径近 5/10 年 PB 分位同理。样式：**浅色底 + 细轮廓**，禁止左侧品牌竖条；**颜色不得单独承载语义**，须配合 `title` 等文案 |

<a id="sec-detail"></a>

## 详情页 `/indices/[code]`

### 用户故事

- **D-R1**：在价格图上切换 **年初至今 / 近 1/3/5/10 年 / 上市来 / 全部**。
- **D-R2**：打开 **70% / 80%** 开关后，看到可视区间内最高价回撤对应的 **水平参照线** 与 **tooltip**。
- **D-R3**：独立的 **估值折线图**（PE/PB 口径依数据可得性）；本迭代至少单独一节折线图。
- **D-R4**：**PE 仪表盘（0–100）** 与 **PE 水位图** 同一行；**PB** 同理下一行。
- **D-R5**：**申万行业构成** 环形图；**一级 / 二级 / 三级** 切换；下方表格表头为 **当前层级名称列 + 权重占比**。

### 功能规格与验收

| #      | 模块                | 规格                                                                                                                                                                                                                                          |
| ------ | ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **D1** | 走势区间            | 选项：**年初至今** · **近 1 年** · **近 3 年** · **近 5 年** · **近 10 年** · **上市来** · **全部**。与摘要估值窗口 **联动策略须产品确认**（建议：默认「近 5 年」，走势图与摘要可独立记忆，见风险节）                                         |
| **D2** | 70 / 80 参照线      | 两路开关（或等价控件）。在 **当前可视区间** 取最高价 `H`，绘制水平线于价位 `H × (1 − 0.70)`、`H × (1 − 0.80)`。Tooltip：**参照跌幅**、**对应价位**、可选相对现价。遵守 `prefers-reduced-motion`；线图色与 `--correlation-chart-line` 体系协调 |
| **D3** | 估值走势图          | **折线图**；横轴交易日；纵轴估值指标（可实现 PE/PB 双线或分开展示）；空数据友好提示                                                                                                                                                           |
| **D4** | PE/PB 仪表盘 + 水位 | 刻度 **0–100**，绑定当前口径下的 **PE 分位**、**PB 分位**。第一行：**PE 仪表盘 \| PE 水位图**；第二行：**PB 仪表盘 \| PB 水位图**。须有 **文本可读数值**；水位填充高度表达同一分位，色盲安全辅以标签                                          |
| **D5** | 行业主营构成        | Segmented：**申万一级 · 申万二级 · 申万三级**。**环形图（donut）** + 图例。**表格**：列 **「申万 X 级名称」**（X 随切换变）、**权重占比**（建议右对齐、tabular nums）                                                                         |

<a id="sec-data"></a>

## 数据与工程假设

- 列表：各行 **PE/PB 当前值**、**当前及近 5/10 年分位**（PE、PB 分列）；排序默认值与缺失策略需产品对齐。
- 详情：**价格序列**（支持 YTD / 上市日截取）、**估值时间序列**、**PE/PB 分位快照**（仪表盘）、**三层申万行业权重**。
- **YTD / 上市来** 依赖交易日历与上市日；MOCK 阶段若缺失须在 UI 标明演示口径。

<a id="sec-risks"></a>

## 风险与待决策

| 议题                        | 选项                                   | 建议                                      |
| --------------------------- | -------------------------------------- | ----------------------------------------- |
| 摘要 Segmented 与走势图区间 | A 完全联动 · B 独立记忆 · C 仅默认一致 | 默认一致 + 走势图 **独立记忆**            |
| 70/80 基准峰值              | 区间内最高价 vs 全历史最高价           | 采用 **当前可视区间最高价**；tooltip 写明 |
| 移动端图表密度              | 折叠 · 横滑 · 简化刻度                 | 卡片留白；窄屏仪表盘可改为 **四卡片栅格** |
