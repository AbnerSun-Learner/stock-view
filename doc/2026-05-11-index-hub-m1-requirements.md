# M1：指数列表 MVP + 详情页（摘要 / 走势图 / ETF 表）——需求拆分

**文档日期**：2026-05-11  
**上游纲要**：`/doc/2026-05-11-index-hub-prd-analysis.md`  
**按页面归类**：`/indices`、`/indices/[code]` 相关内容见 `/doc/index-hub-prd/page-indices-list.md`、`page-indices-detail.md`。
**M1 定义**：交付 **可演示的闭环 URL**——用户可从「指数列表」进入「单指数详情」，在详情内阅读 **估值摘要、周期走势图、跟踪 ETF 对照表**。  
**M1 明确不包含**：首页/全局导航新增入口、网格与 correlation 的深度链接预填、列表双选跳转对比、服务端缓存与 ISR 专项（归入 M3 或与工程并行时另立工单）。

---

## 1. 目标与验收口径

### 1.1 产品目标

- 提供站内第一条 **「扫目录 → 看单指数 → 理解估值与载体」** 路径，为 M2 导流工具打基础。
- 同一套 **周期语义（1Y / 5Y / 10Y / ALL）** 在详情摘要与图表间保持一致，避免认知冲突。

### 1.2 M1 完成定义（Definition of Done）

| #   | 验收项                                                                                              |
| --- | --------------------------------------------------------------------------------------------------- |
| D1  | 存在稳定列表路由（如 `/indices`），表格展示指数集合，行可跳转详情                                   |
| D2  | 存在稳定详情路由（如 `/indices/[code]`），非法或未知 code 有统一空态/错误页                         |
| D3  | 详情首屏含：**估值摘要区**（至少 PE 或统一主口径 + 分位/相对描述，含数据日期）                      |
| D4  | 详情含 **走势图**：支持 1Y / 5Y / 10Y / ALL 切换，默认周期与摘要默认窗口一致                        |
| D5  | 详情含 **跟踪 ETF 表**：至少代码、名称；规模/费率/流动性等字段按「数据可得」展示，无数据列允许「—」 |
| D6  | 列表与详情在桌面端可用；窄屏下表格可横向滚动或等价可读方案                                          |
| D7  | 页级 `title`（及可选 `description`）对列表页与详情页区分，便于书签与分享辨认                        |

## 2. 范围边界

### 2.1 In Scope（M1 必做）

- 指数列表页：展示、排序、基础筛选、跳转详情。
- 指数详情页：摘要卡片、走势图（价格指数为主）、ETF 对照表。
- 站内设计一致性：沿用现有 Stillwell 导航壳（可与 `/grid`、`/correlation` 同顶栏 pattern）、品牌色与无障碍对比度。

### 2.2 Out of Scope（M1 不做，避免阻塞）

- 「打开网格」「发起对比」等 **带 query 的深链**（M2）。
- 首页 Hero / header **第三条全局入口**（可与 M2 一并上线，避免两次改导航）。
- 列表 **双选 + 浮动对比条**。
- 用户登录、收藏、自定义列。
- 走势图 **brush 区间选取**、PE/PB **双轴叠加**（若工期紧：M1 仅价格指数单系列；PE 可走摘要数字 + 二期叠加）。
- 成分股、相关指数推荐、打印/PDF。

### 2.3 依赖与假设（开工前需对齐）

- **指数主数据源**：字段包含代码、名称、类别、估值序列或预聚合分位、日线收盘价序列、数据截止日期。
- **指数–ETF 映射**：至少有「一对多」列表；若无跟踪误差等指标，M1 表格仅展示可得列。
- **路由参数规范**：`code` 的规范化规则（大小写、交易所后缀）与列表、详情、后续 API 一致。

## 3. 信息架构与路由

### 3.1 路由建议

| 路由              | 用途                                  |
| ----------------- | ------------------------------------- |
| `/indices`        | 指数列表                              |
| `/indices/[code]` | 指数详情，`code` 为规范化后的指数代码 |

### 3.2 列表 → 详情

- 点击行或主列「名称 / 代码」进入 `/indices/[code]`。
- 支持浏览器后退返回列表且 **保留滚动位置或筛选状态**（M1 最低标准：返回列表不强制丢状态；若仅用 URL 无状态，接受首版仅保留排序/筛选在 session 内——需在实现备注中写明）。

## 4. 指数列表页——需求拆分

### 4.1 用户故事

| ID   | 角色 | 我想要                                 | 以便于                                      |
| ---- | ---- | -------------------------------------- | ------------------------------------------- |
| L-01 | 访客 | 在一页上看到多只指数的代码、名称与类别 | 快速扫描目标标的                            |
| L-02 | 访客 | 按类别筛选或关键词搜索                 | 缩小候选范围                                |
| L-03 | 访客 | 按某一估值相关列排序                   | 发现相对高估/低估标的（在口径允许的前提下） |
| L-04 | 访客 | 点击某一指数进入详情                   | 查看走势与 ETF                              |

### 4.2 字段与列（M1 最小列集）

| 列                          | 说明                            | 优先级 |
| --------------------------- | ------------------------------- | ------ |
| 指数代码                    | 主键展示，等宽或 monospace 可选 | P0     |
| 指数名称                    | —                               | P0     |
| 类别                        | 枚举来自产品词典                | P0     |
| 当前 PE（或站点统一主口径） | 数值 + 小数位规则统一           | P0     |
| 近 5 年分位                 | 百分比或「XX%」；口径 Tooltip   | P0     |
| 近 10 年分位                | 同上；若无 10 年数据显式「—」   | P1     |
| PB 相关列                   | 仅当该指数站点约定展示 PB 时    | P1     |

**说明**：若 PRD 中「指数估值」定义为综合分，M1 **不新增独立打分列**，以免与 PE/PB 重复；综合分放入 M2+。

### 4.3 交互细则

- **筛选**：至少支持「按类别」；可选关键词搜索（匹配名称或代码子串）。
- **排序**：至少支持按「代码」「名称」「当前 PE」「近 5 年分位」「类别」之一排序；默认排序策略产品指定（建议：按类别分组内按代码，或按流动性/规模相关的静态权重——若无则按代码升序）。
- **分页**：数据量 >100 时服务端或客户端分页（阈值与每页条数在实现单写明）。
- **加载**：首屏骨架或表格占位；失败时错误提示 + 重试。
- **空态**：筛选结果为空时提示「无匹配指数」并一键清除筛选。

### 4.4 验收标准（列表）

- 给定不少于 N 条样本数据（N≥10），表格渲染正确且排序结果可复现。
- 非法筛选组合不产生前端报错。
- 键盘或可访问性：行导航可达（最低：链接可被 Tab 聚焦）。

## 5. 指数详情页——需求拆分

### 5.1 用户故事

| ID   | 角色 | 我想要                                             | 以便于               |
| ---- | ---- | -------------------------------------------------- | -------------------- |
| D-01 | 访客 | 看到该指数的概况与数据更新日期                     | 判断信息新鲜度       |
| D-02 | 访客 | 看到当前估值在近 1/5/10 年及全历史窗口下的相对位置 | 判断贵贱（在口径内） |
| D-03 | 访客 | 切换 1Y/5Y/10Y/ALL 查看价格走势                    | 与摘要窗口对齐       |
| D-04 | 访客 | 看到跟踪该指数的 ETF 列表及关键字段                | 选择交易载体         |

### 5.2 模块 A：页面头与估值摘要

**内容**

- 标题区：指数名称 + 代码；可选副标题：类别。
- **数据截至**：`asOfDate`（交易日或数据源标注），显著展示。
- **口径说明**：折叠或链接至简短说明（PE 定义、是否 TTM、缺失交易日处理原则——内容由数据方对齐，UI 占位即可）。
- **摘要指标**（与周期联动，见 5.3）：
  - 当前 PE（主口径）；
  - 在当前选中窗口下的 **分位数**（或产品确认的等价表述）；
  - 若站点对 PB 有约定：同步展示 PB 与分位。

**默认窗口**：建议 **5Y**，与列表默认排序/用户心智对齐；若列表强调 10 年，则默认 10Y——**全站唯一默认**，写在配置或常量中。

**边界**

- 数据缺失：展示「暂无估值」并说明原因（如新指数历史不足）。
- `code` 不存在：404 或专用「未找到该指数」页，提供返回列表链接。

### 5.3 周期联动规则（强制）

- 全局周期：`1Y | 5Y | 10Y | ALL`，控件形态为 Tab 或 Segmented。
- **摘要卡片展示的「当前窗口分位」** 必须与 **走势图可见区间** 一致。
- 切换周期时：摘要数字与图表 **同步更新**；加载中显示 skeleton 或图表 loading，避免展示混搭窗口的数据。

### 5.4 模块 B：走势图

**M1 最小交付**

- X 轴：交易日期；Y 轴：**指数收盘价（复权规则与数据源一致，须在脚注说明）**。
- 周期切换过滤数据区间；ALL 展示全样本。
- Tooltip：日期 + 收盘价（可选涨跌额省略）。
- 空数据：友好文案。

**M1 可选（工期允许）**

- 第二面板或 Tab：**同区间 PE 走势图**（仍受同一周期控件约束）。

**非 M1**

- K 线蜡烛图、成交量、brush、导出图片。

### 5.5 模块 C：跟踪 ETF 对照表

**列（按可得性降级）**

| 列                | P0  | 说明       |
| ----------------- | --- | ---------- |
| ETF 代码          | ✓   |            |
| ETF 名称          | ✓   |            |
| 基金规模          | ○   | 无则「—」  |
| 管理费率          | ○   |            |
| 近 N 日日均成交额 | ○   | 表征流动性 |
| 折溢价率          | ○   |            |
| 跟踪误差          | ○   |            |

**排序**

- 默认：**规模降序**；规模并列时按成交额降序。若两项皆无，按代码升序。

**交互**

- 行内可复制代码（可选 M1 低成本：展示可选中文提示「长按复制」或图标按钮）。
- **不包含** M1 的「打开网格」按钮（M2）。

### 5.6 验收标准（详情）

- 切换四个周期时，摘要与图表数据源区间校验一致（抽样 3 个指数手工对照日期边界）。
- ETF 表至少展示 P0 列；映射为空时模块展示「暂无跟踪 ETF 数据」。
- Lighthouse 或人工：无明显 CLS（图表容器预留高度）。

## 6. 错误、加载与文案

| 场景             | 行为                                                  |
| ---------------- | ----------------------------------------------------- |
| 列表 API 失败    | 错误提示 + 重试；不白屏                               |
| 详情概要失败     | 区分「指数不存在」与「服务异常」                      |
| 图表序列部分缺失 | 线上可用区间内绘图；备注说明截断原因                  |
| SEO              | 列表页通用 description；详情页 title 含指数名称与代码 |
