# 跨页面 PRD：背景、导流、竞品、迭代与待决策

**摘录来源**：`/doc/2026-05-11-index-hub-prd-analysis.md` §1、§4（导流总览）、§6–§9；`/doc/2026-05-11-index-hub-m1-requirements.md` §2、§7–§9

---

## 1. 背景与 Why Now（纲要 §1）

- **问题**：缺少可扫描的指数目录，工具链入口断层、手输成本高。
- **时机**：补上目录层，形成「投研工作台」心智；指数内容读多写少，适合稳定 URL 与 RSC/SSR 策略。

## 2. 成功标准（纲要 §1.3）

| 维度     | 信号                                     |
| -------- | ---------------------------------------- |
| 触达     | 首页/导航 → 列表 UV；列表 → 详情 CTR     |
| 任务完成 | 详情 → 网格预填 / 对比（M2+）            |
| 信任     | 数据日期与口径说明清晰                   |
| 性能     | 列表/详情首屏体感；对齐技术文档 O2/O3/O4 |

## 3. 站内导流总览（纲要 §4）

- **URL 规范**：列表 `/indices`；详情 `/indices/[code]`；`code` 全站规范化。
- **列表/详情 → 网格**：深链与文案（见 `page-grid.md`）。
- **列表/详情 → correlation**：深链与双选（见 `page-correlation.md`）。
- **工具 → 指数档案**：反向链接闭环。

## 4. 与 ETF.run 差异化（纲要 §6）

- ETF.run：**泛读**、静态估值消费。
- Stillwell：**精读 + 行动**（网格、持仓分散度复检）；强调口径透明与同工具链标的映射。
- 避免只做字段对标；详情首屏突出「下一步动作」（M2）。

## 5. 迭代切片（纲要 §8）

| 切片 | 内容                              | 产出           |
| ---- | --------------------------------- | -------------- |
| M1   | 列表 + 详情（摘要/走势图/ETF 表） | 可演示闭环 URL |
| M2   | 深链 + 导航入口                   | 转化率可测     |
| M3   | 缓存、岛屿式、`loading`、FACTS 等 | 弱网与 SEO     |
