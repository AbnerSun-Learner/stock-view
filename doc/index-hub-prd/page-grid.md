## 1. 与本功能的链接设计（纲要 §4.2，多为 M2）

- **深链预填**：`?symbol=` 或 `?etf=`（与 `useGridParams` 对齐）。
- 文案：「打开网格」「用该基金测算网格」——从估值进入策略实验。

## 2. 反向链接（纲要 §4.4）

- 网格页结果区或侧栏：**「查看该标的指数档案」** → `/indices/[code]`（依赖指数 ↔ 代码映射）。
- ETF 仅输入时：能映射则链到跟踪指数详情。

## 3. 优化方向（纲要 §5.1）

- **预填与模板**：从指数详情带入代码后的保守/中性默认参数。
- **解释性**：stats 卡片链到指数详情估值口径或站内说明。
- **工程**：岛屿式 Client、控制首包（见 `/doc/2026-05-11-stock-view-vs-etfrun-architecture-and-optimization.md` O3）。

## 4. M1 边界

- M1 **不包含** 从详情/API 跳转网格的深链实现（M1 文档 §2.2）；本页在 M1 可无代码改动，仅在 PRD 中预留契约。
