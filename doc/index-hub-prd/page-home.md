## 1. 当前状态（基线）

- 导航含：网格交易、指数对比、关于。
- 工具卡片区：`TOOLS` 含网格、压力测试（指向 `/grid`）、指数对比（`/correlation`）。
- `FACTS` 中含「计算方式」等文案；纲要要求后续 **按工具拆分** 服务端/本地表述（见 `page-correlation.md` 与 `cross-cutting.md`）。

## 2. 与本功能相关的规划（按迭代）

### M1（当前不做）

- **不在 M1 范围**：首页 Hero / header **第三条全局入口**（「指数」「指数目录」）；可与 M2 一并上线以免两次改导航。（出处：M1 文档 §2.2）

### M2+（纲要）

- **全局导航**：header 增加第三入口 **「指数」或「指数目录」**，与 `/grid`、`/correlation` 并列。（纲要 §4.1）
- **落地卡片区**：可增加第四张工具卡片或调整文案，指向 `/indices`（实施时与视觉稿一致即可）。

## 3. 成功度量中与首页相关的部分

- **触达**：从首页 / 导航进入指数列表的 UV（纲要 §1.3）；M1 未上线导航时，该指标在 M2 启用导航后再采。

## 4. 术语与一致性

- 「指数对比」与 URL `/correlation` 并存时，关于区可用一句话说明对比的是 **收益联动与持仓重叠等信号**（纲要 §5.3）。
