指数列表与详情页 — 迭代 PRD

日期：2026-05-11 · 格式：HTML 单一可读副本 · 替換此前的 Markdown M1 详拆与按页摘录（列表 / 详情）· 与设计令牌对齐：--correlation-brand、--correlation-card-tint、极简边框与高可读正文。

为什么要现在做：用户需在同一心智路径内完成「扫列表估值极端信号 → 进详情看多周期走势与估值上下文」。仅靠单列摘要不足以对比 PB、也不够提示当前分位是否显著低于中长期窗口；详情侧缺少估值序列可视化与行业权重拆解时，决策链路仍会跳出到站外。

如何判定成功：列表在无横向溢出观感崩塌前提下可读 PE/PB 双口径极端标注；详情用户在两次以内交互可切换到任意预设区间并在图上读出回撤参照线；估值仪表盘与水线图在无指针交互情况下仍可读出0–100 分位语义（辅以简短文案）；行业构成切换层级后图例与表头语义同步更新。

1. 范围与非目标

类型 说明
In scope 本迭代所列列表表结构、单搜索筛选、分位极端视觉标注规则；详情价格走势图控件扩充、70%/80% 回撤参照线、估值折线图、PE/PB 仪表盘 + 水位图两行布局、申万三级切换环形图 + 表格。
Out of scope 登录收藏、自定义列、实时推送刷新； 暂缓 brush 区间选取导出； 与网格 / correlation 的深链预填（另工单）。

2. 列表页 /indices

2.1 用户故事

  • L-R1：我希望表格列宽贴近表头与单元格真实字数，以避免整块留白或过窄挤压。
  • L-R2：我需要同时扫描 PE 与 PB 的当前值与中长窗口分位，且不丢失类别之外的更多信息。
  • L-R3：我希望仅用一个搜索框缩小候选集，且控件固定在表格卡片右上方。
  • L-R4：当当前分位同时低于近 5 年与近 10 年分位（三者皆有有效数值）时，我需要非单凭色相即可理解的标注（底色 / 描边 + title 或等价无障碍说明）。

2.2 功能规格

# 需求 验收要点（Given / Then）
L1 列宽自适应内容 使用 table-layout: auto（或等价策略）；表头与单元格均参与最小宽度计算；桌面端不出现无理由的过宽空白列。
L2 表头不换行 CSS white-space: nowrap；窄屏允许表格外层横向滚动而非压缩折行。
L3 列：移除类别 列表不再渲染类别列；后端仍可保留字段供 MOCK。
L4 列：当前 PB、当前 PB 分位（用于与 §L6 规则对齐）、近 5 年分位（PB）、近 10 年分位（PB） 与 PE 侧并列可读；缺失数据显示「—」；若无上当前 PB 分位字段则 PB 侧标注规则不触发。
L5 筛选：单一搜索 仅保留关键词搜索（代码或名称）；置于表格卡片内右上；具备可见 aria-label，触摸目标高度 ≥ 44px。
L6 分位极端双色标注 分别对 PE、PB 判定：当前 PE 分位与当前 PB 分位（字段须存在）相对各自的近 5 年、近 10 年分位： 当前 !== null 且 当前 < min(近5年, 近10年)（严格小于）时标注； 样式：浅色底 + 细轮廓，禁止左侧品牌竖条；颜色不得单独承载语义，须配合 title 文案说明含义。

3. 详情页 /indices/[code]

3.1 用户故事

  • D-R1：我需要在价格图上快速切换年初至今 / 多档滚动窗口 / 上市来 / 全历史。
  • D-R2：我希望打开70% / 80%开关后，看到自可视区间内最高价回撤对应价位的水平参照线与精确 tooltip。
  • D-R3：我需要估值折线图（PE、PB 或统一口径由数据可得性决定）与价格走势解耦或可选叠加——本迭代至少单独一节折线图。
  • D-R4：我需要PE 仪表盘（0–100）与PE 水位图同一行；PB 同理下一行。
  • D-R5：我需要申万行业构成环形图，并可在一级 / 二级 / 三级间切换；下方表格表头为当前层级名称列 + 权重占比。

3.2 功能规格

# 模块 规格
D1 走势区间 Segmented 选项：年初至今 · 近 1 年 · 近 3 年 · 近 5 年 · 近 10 年 · 上市来 · 全部； 与摘要卡片估值窗口联动策略需产品确认默认值（建议：默认仍为「近 5 年」，切换走势图不强制覆盖摘要窗口，或反之——见风险节）。
D2 70 / 80 参照线 两个独立开关（或分段控件）；开启后在当前可视区间内取最高价 H，绘制水平线于价位 H × (1 − 0.70) 与 H × (1 − 0.80)； Tooltip 展示：参照跌幅、对应价位、可选相对现价间距； 遵循 prefers-reduced-motion；线图配色与现有 --correlation-chart-line 体系统一。
D3 估值走势图 折线图；横轴为交易日时间；纵轴为估值指标（实现阶段可选 PE/PB 双线或分开展示）；空数据友好提示。
D4 PE / PB 仪表盘 + 水位图 刻度固定 0–100，绑定当前选定口径下的 PE 分位与PB 分位； 第一行：PE 仪表盘｜PE 水位图；第二行：PB 仪表盘｜PB 水位图； 仪表盘需文本读出数值（不仅依赖指针角度）；水位图用填充高度表达同一分位，满足色盲安全辅以前景色标签。
D5 行业构成 Segmented：申万一级 · 申万二级 · 申万三级； 环形图（donut）图例可点击或并列展示行业名称； 下方表格列：「申万X级名称」（X 随切换变）与权重占比（百分比，建议右对齐、tabular nums）。

4. 数据与工程假设

  • 列表接口需提供各行：PE/PB 当前值与当前及 5Y/10Y 分位（PE、PB 分列）；缺失策略与列表排序默认值与产品对齐文档。
  • 详情需提供：价格序列（支持 YTD / 上市日截取）、估值时间序列、PE/PB 分位快照（供仪表盘）、三层申万行业权重。
  • YTD / 上市来依赖日历锚点（交易所日历）与上市日期字段；若 MOCK 阶段缺失，允许占位但须在 UI 标明演示口径。

5. 风险与待决策

议题 选项 建议
摘要 Segmented 与走势图区间 A 完全联动 · B 独立记忆 · C 仅默认一致 默认一致 + 用户改动走势图独立记忆（降低跳转迷路）。
70/80 基准峰值 区间内最高价 vs 全历史最高价 PRD 采用当前可视区间最高价；需在 tooltip 写明。
移动端图表密度 折叠次要序列 · 横向滑动 · 简化刻度 沿用站内「卡片 + 合理留白」；窄屏估值仪表盘两行纵向堆叠为四卡片栅格亦可接受。
